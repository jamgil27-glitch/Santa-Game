# 🎄 Santa Game

A festive, fun Christmas-themed game where you help Santa catch falling gifts!

## 🎮 Game Overview

Santa Game is an exciting seasonal game that challenges you to catch as many falling gifts as possible. Use your quick reflexes and keyboard skills to guide Santa across the screen and maximize your score before you run out of lives.

## 🎯 How to Play

- **Objective**: Catch falling gifts to earn points
- **Controls**: Use the **Arrow Keys** (← →) to move Santa left and right
- **Lives**: You start with **4 lives**
- **Penalty**: Miss a gift and you lose one life
- **Game Over**: Lose all 4 lives and it's game over!

## 🏆 Scoring & Competition

- **Points**: Each gift you catch adds to your score
- **Leaderboard**: Compete with friends to see who can get the highest score
- **Challenge Friends**: Share your high score and try to beat theirs!

## 🎁 Features

✨ Festive Christmas atmosphere
🎅 Control Santa with easy-to-learn controls
🎄 Falling gift mechanics
❤️ 4-life system for added challenge
📊 Score tracking for competitive play
👥 Multiplayer competition (local)

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/jamgil27-glitch/Santa-Game.git
```

2. Navigate to the project directory:
```bash
cd Santa-Game
```

3. Open `index.html` in your web browser to play!

## 🎮 Getting Started

Simply open the game in your browser and start playing. Use the arrow keys to move Santa and begin catching those gifts!

## 📝 Tips for High Scores

- Stay focused and anticipate where gifts will fall
- Move quickly but strategically
- Try to catch every gift to maximize your score
- Practice to improve your reflexes!
